# Live evaluation runtime

Qwen remains the fixed agent model for v1–v4. Following the user's authorization to use Qwen/Groq to complete execution, the independent judge is Groq GPT-OSS-20B. Gemini remains configured as an alternative, with its observed 5 RPM limit respected. Set JUDGE_PROVIDER=groq, JUDGE_MODEL=openai/gpt-oss-20b, JUDGE_API_KEY to the active local Groq key, and JUDGE_REQUEST_INTERVAL_SECONDS=10. Native Evidently LLMEval uses a registered LiteLLM wrapper with low reasoning effort and a 512-token completion ceiling.

The scratch harness admits at most four concurrent queries. Every completed sample is checkpointed before the next stage. Resuming preserves actual outputs and token usage; it does not synthesize repetitions. Checkpoint identity covers cases, repeats, configuration, prompt, model and endpoint. Changed inputs reject stale checkpoints. Partial runs are explicitly tagged and marked KILLED in MLflow when stopped.

Identical native judge inputs share a cached verdict. Cache identity includes model, full judge messages (criteria, query, reference, response), and generation settings. Cached text is parsed using the current native descriptor parser. Changed criteria or answers require new requests. Agent samples remain independent. The synchronous native descriptor adapter is tested, not just an asynchronous helper. Calibration reuse additionally checks labels, approved review, provider/model and implementation identity. Native reports include every original row and its resolved verdict. The local judge cache is git-ignored; a clean clone makes fresh calls.

Groq reserve keys can fail over only following authentication rejection (401/403), only for api.groq.com, and only without proxy cookies. HTTP 429 retains the current key and respects numeric Retry-After with bounded backoff. Shared account/project quotas are not bypassed. Primary Jupyter credentials remain separate from Groq credentials. Native SDK errors suppress credential-bearing exception chains.

Run stages with the README experiment commands. Re-running the exact command resumes completed samples. For an intentional fresh repetition, use a new version or archive the old evaluation directory first; do not silently delete evidence. Judge calls are paced and may take several minutes. Full metrics, gate decisions and report artifacts are recorded only after the stage genuinely completes. An evaluation-only run has no judge metrics and cannot be promoted.
