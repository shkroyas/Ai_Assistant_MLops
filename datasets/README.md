# Dataset card
The corpus is an authored **fictional company handbook**, not a claim about an actual organization. JSONL references are authored from its explicit facts, never assistant outputs. Dev has 35 cases across seven categories; golden has 18 fixed regression cases; calibration has 15 proposed calibration responses (7 deliberately wrong). Golden paraphrases overlap development facts: this is a regression set, not an independent generalization benchmark. These labels were drafted during implementation, not hand-labeled by the user. Human review of calibration labels is pending; report this limitation. Do not tune prompts on golden responses. Failure-injection cases disable retrieval persistently. Schema validation runs in tests.
